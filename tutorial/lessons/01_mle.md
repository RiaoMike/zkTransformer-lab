# 1 · 先让一张数组变成多项式

论文：§2.4.1、引理 2.2；然后读 §3 的批量矩阵乘法反例。
原库：[poly.rs](../../upstream/src/util/poly.rs)，定位 `DenseMLPoly::fix_variables`。

## 为什么先学这个

模型输入、权重和中间张量都是数组，但证明协议最终会问：
“这张数组对应的多项式，在挑战点 `r` 上的值是多少？”
`MLE` 是多线性延拓，每个变量单独的次数最多为 1。长度为 `2**n` 的数组保存的是
布尔点上的**求值**，不是系数。引理 2.2 说明这些值唯一确定一个 MLE。

本课程固定用模 101 的域做小例子；`100` 表示 `-1`。除法要乘域逆元，不能用浮点数。
原库使用 BN254 标量域；更换模数不会改变本课的插值公式。

## 第一步：只写一个变量

若 `A=[a,b]`，唯一的一次插值是：

$$\widetilde A(t)=(1-t)a+tb=a+t(b-a).$$

在 `exercises.py` 实现 `fold`。用步长为 2 的循环依次读取相邻元素：

先在 REPL 检查 `fold([1,2,3,4],2)` 是否得到 `[3,5]`。

## 第二步：固定多个变量

约定第一个变量对应下标最低位，表的顺序为：

| 下标 | `(b0,b1)` | 值 |
|---|---|---|
| 0 | `(0,0)` | 1 |
| 1 | `(1,0)` | 2 |
| 2 | `(0,1)` | 3 |
| 3 | `(1,1)` | 4 |

实现 `mle(table,point)`：复制数组、检查维数、对每个挑战调用 `fold`、返回最终值。
手算并写在笔记里：

```text
[1,2,3,4] --r0=2--> [3,5] --r1=3--> [9]
```

零变量的表 `[7]` 在空点 `[]` 上的值应是 7。

## 第三步：用定义式重新理解

实现 `eq(r,b)`：

$$\operatorname{eq}(r,b)=\prod_j(r_jb_j+(1-r_j)(1-b_j)).$$

那么

$$\widetilde A(r)=\sum_{b\in\{0,1\}^n}A[b]\operatorname{eq}(r,b).$$

比如 `eq([2],[0])=100`，`eq([2],[1])=2`；它不是一般意义上的相等比较。
验收器用这个定义式检查你的折叠算法，两个计算路径应当一致。

```bash
python3 tutorial/check_exercises.py 1
```

## 第四步：亲手制造一个错误等式

设 `A=[1,2]`、`B=[3,5]`、逐元素乘积 `C=[3,10]`。先分别写出三个 MLE：

$$\widetilde A(t)=1+t,\quad\widetilde B(t)=3+2t,\quad\widetilde C(t)=3+7t.$$

在 `t=2` 计算：

| 表达式 | 结果 |
|---|---:|
| `mle(C,[2])` | 17 |
| `mle(A,[2])*mle(B,[2]) % 101` | 21 |
| `sum(eq([2],[u])*A[u]*B[u] for u in [0,1]) % 101` | 17 |

为什么第二个结果不同？两个一次多项式的乘积一般是二次多项式，不能直接应用 MLE 唯一性。
`eq` 加权的布尔求和把输出重新多线性化；这就是下一节的核心。
